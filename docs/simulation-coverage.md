The seeds cover both skipped/ranked continuations and success/fallback finale endings. [Test source](../test/simulation-properties.test.mjs). This bounded three-player, injected-clock exploration is not exhaustive state-space, all-chapter or capacity proof; its source hashes name the four measured files explicitly.
- **Completed normal-clock event:** frozen `f7ea6a8`, 100 participants joining over 60.005 seconds, two operators and a presentation stream; 3,607.001 seconds of event play through awards, process exit 0. Independent [QA summary](../test-results/capacity-current-f7ea6a8.qa-summary.json) recomputes all 75,944 raw confirmed-action timings (none dropped), including 12,452 scoring/inventory actions: event-wide p95 **251.857ms**, p99 **333.208ms**. All fifteen distinct qualifying awards, inventory, recorded outcomes, exact completion times and journal binding independently reconcile with no gaps. All 103 identities received all 18 expected phase boundaries: 1,854 observations, none early, maximum 376ms. One stored lag differs from its separate receipt timestamp by 1ms; the recomputed schedule still passes. All fourteen declared source hashes match the frozen commit.
- **Capacity measurement limits:** this was localhost Node HTTP/SSE in one process on a shared development machine, with concurrent native review and combined-suite activity. Timings end after successful response JSON parsing, not browser painting. Aggregate p95 meets 500ms; it does **not** mean every chapter or tail latency does: chapter 6’s 750 scoring samples have p95 **612.427ms** and p99 **731.003ms**; chapter 8 p99 is **701.985ms**. These observed hotspots remain in the QA summary without attributing a cause. The loaded runtime predates paused-End-scoring fix `509854b` and later client changes, which have separate current-source regressions and native evidence. Historical `d042570` remains historical evidence, not a substitute for this run or current client artwork.
- **Client adapter:** tests execute actual functions extracted from `public/app.js`, with a small DOM adapter and real Engine dispatch/projections. They test input-to-action, visible text, selection, focus, pending and stale-response behavior. The generic chapter fixture explicitly places the actor at each target and selects chapter/clock conditions; its optional-challenge gate fixture explicitly sets main completion. These are conditional UI behavior checks, not browser layout, pathfinding or legitimate discovery evidence. The HTTP scenario supplies movement and full-sequence evidence separately.
- **Actual renderer calls:** tests execute current Canvas functions and inspect their paint operations, crowd bounds, marker ordering and robot replacement. They establish specific rendering invariants, not visual quality, display scaling or FPS.
- **Native review:** [current native ledger](simulation-native-review.md), [browser checks](browser-checks.md), [controls matrix](controls-matrix.md) and the new review artifacts retain their exact revisions and fixture limits. The historical 48 keyboard/pointer main/learning cells cannot silently certify the new Move Day interface. Current native observations are appended by the browser-owning reviewer.

## Defects found by this pass

1. **Paused End scoring bypassed its real phase guard.** Paused countdown could freeze before scoring began; paused finale could reset its clock. The original two failing cases are preserved in `simulation-host-before-fix.log`. Fix `509854b` restricts paused End scoring to chapter/brag; both rejection tests and actual normal host recovery paths pass.
2. **Rescue retained a route whose next segment was blocked from the new position.** The player stalled at `(368,264)` aiming at the depot. The client now checks authoritative relocation against its next waypoint and replans without inventing movement or scoring. The independent actual frame test completes the original destination exactly once.
3. **Several delayed dialog callbacks could replace a newer dialog or submit twice.** Current client adapters reproduce quiz, secret, mystery, trade and tutorial pending/modal-revision conditions; the fixes retain current panel/focus and suppress stale feedback. Settings keeps successful safety persistence while avoiding closing a newer modal.
4. **Obsolete operator failures could appear after connection replacement.** Host command success already checked its captured connection generation; the error path now uses the same guard. The delayed-failure regression rejects stale feedback.
5. **Crowding protection was limited to chapter one.** The overview now caps nearby representatives in every phase, preserves self, keeps approaches clear and removes stacked name/emote overlays. The full roster remains in Neighbors. The recipient-facing Neighbors label now shows the active preset, replaces/expires in place and preserves focus; this regression passes.
